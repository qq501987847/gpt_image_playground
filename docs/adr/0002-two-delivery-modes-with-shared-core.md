# ADR-0002：以共享核心支持在线版与桌面版

## 状态

已接受

## 背景

AWAI创作工作台需要同时作为 Sub2API 自定义菜单中的在线 iframe 和可长期保存素材的 Tauri 桌面应用使用。浏览器 IndexedDB 与 OPFS 可满足在线版的本地历史，但无法为桌面版提供稳定、可选目录的文件保存能力；在线云端副本也不能依赖前端计时清理。

## 决策

保持单一 UI 与生成核心，按运行模式替换认证、素材存储和网络传输适配器。

- 在线嵌入版由 Sub2API 自定义菜单在 iframe URL 中传入 `user_id`、`token`、主题、语言和嵌入上下文。应用启动后把 token 写入 `sessionStorage`，并以 `history.replaceState` 立即从地址栏移除 token；响应设置 `Referrer-Policy: no-referrer`。浏览器历史的元数据与文件索引保存在 IndexedDB，图片保存在 OPFS；云端副本固定保留 24 小时。
- 云端副本存入 S3 兼容对象存储，数据库只保存任务、对象路径和 `expires_at`；对象存储生命周期负责删除，后台清理任务负责补偿，并删除原图、缩略图和数据库记录。
- 云端临时保存默认开启；首次进入明确说明生成结果原图和缩略图将在云端保留 24 小时。用户可关闭后续上传，也可立即删除已有云端副本；每份素材展示准确到期时间。
- 云端临时保存只包含生成结果原图和对应缩略图，不保留参考图、遮罩或其他输入附件；请求处理产生的输入临时数据在请求结束后释放。
- 本地桌面版使用 Tauri 宿主，把素材和元数据写入用户选择的素材库目录，并通过系统凭据库保存敏感配置；它独立运行，不以 iframe 加载本机服务。首发不引入项目列表或项目切换概念。
- 桌面首发由用户手动粘贴一个或多个 Sub2API Key，不增加 OAuth、Deeplink 或批量配置包导入。Key 可被多个 API 配置复用；后续 Sub2API 复合分组可在不改变客户端绑定模型的前提下减少用户需要录入的 Key 数量。
- 桌面 Key 是跨素材库共享的应用全局凭据，明文只写入 Windows 凭据管理器或 macOS 钥匙串。素材库元数据与 AWAI 备份包只保存凭据 ID；在另一台设备导入备份或本机凭据已删除时，相关 API 配置进入“需要重新绑定”状态，不尝试从备份中恢复 Key。
- 桌面应用采用单实例模式，同一用户会话中只允许一个进程。再次启动应用时唤醒已有窗口，不创建第二个实例。存在运行任务时禁止更改素材库目录。
- 两种模式均提供立即下载与打包下载。
- 两种模式使用统一的 AWAI 备份 ZIP 格式，首发即支持用户手动导出和导入完整历史。备份包包含图片及恢复任务、收藏和 Agent 对话所需的元数据，但不作为自动云同步机制。
- 导入备份包只合并到当前素材库，不覆盖当前记录，也不提供“清空后恢复”。任务、图片、收藏或对话 ID 冲突时生成新 ID，并同步修正包内引用关系。

## 后果

静态前端之外需要新增在线服务端和 Tauri 本地宿主，并产出 Web 与桌面安装包两类构建物。认证、对象存储、任务元数据、目录写入和跨域传输由模式适配器负责，UI、生成逻辑和 Sub2API 接口适配保持共享。在线版不以浏览器定时器作为数据删除机制，桌面版也不把 IndexedDB 作为长期素材的唯一来源。

Sub2API 自定义菜单传入的是控制台 JWT，Sub2API 模型网关另行要求用户 API Key。在线版使用 JWT 读取用户自己的 API Key 列表，由用户根据所属分组、价格和状态为每个 API 配置明确绑定 Key。Agent 文本、Gemini 和 OpenAI 兼容图像配置可分别绑定不同 Key。AWAI 不自动创建、修改或替用户选择 Key。

在线版仅按 `Sub2API 地址 + user_id + API 配置 ID` 持久化对应 Key ID，不持久化 Key 明文。每次进入时使用 JWT 重新读取 Key 列表并逐项验证绑定；Key 已删除、停用或过期时只禁用受影响的配置，并要求用户重新选择。

在线版创建或编辑 API 配置时，用户先选择 Key，应用再携带该 Key 请求相应协议的模型列表，最后由用户选择模型。不同 Key 的模型列表不合并；手动模型 ID 保留为独立的“自定义模型”入口，且界面明确其可用性尚未验证。

在线 iframe 始终使用 Sub2API 注入的 `src_host`。桌面版使用固定的官方逻辑域名，实际后端由 DNS 或负载均衡切换，不向用户展示备用节点；只有逻辑域名整体不可达时，桌面版才读取并验证签名灾备地址清单。生成请求在结果未知时不得跨节点自动重试，以免重复生成和扣费。

在线部署必须配置精确 HTTPS origin 允许列表，包含当前主域名和已批准的备用域名。应用在使用任何菜单 JWT 或 API Key 前验证 `src_host`；未命中允许列表时不向该地址发送凭据，并显示入口无效。允许列表不接受通配符。

两种运行模式都不允许用户编辑模型请求域名，也不提供 FAL、Google 官方或任意自定义 HTTP 供应商直连入口。

“关于”页展示 AWAI 名称、版本和运行模式，唯一官方支持入口由部署变量 `AWAI_SUPPORT_URL` 指定。页面不展示 GitHub、赞助或上游反馈链接。

桌面版不检查、下载或安装自动更新，也不集成 Tauri updater。用户通过手动安装新版 NSIS/DMG 升级，安装与升级验收必须验证素材库、SQLite 数据和系统凭据引用保持可用。

首发只发布稳定版安装包，不提供 Beta、灰度比例或用户侧渠道切换。

项目现在及未来均不要求 Authenticode、Developer ID、notarization 或 Tauri updater 签名。发行说明必须明确安装包未签名可能触发的 SmartScreen/Gatekeeper 提示。

桌面版在 Windows 10/11 与 macOS 同步首发，Linux 不在首发范围。两端发布门槛均包含首次安装、素材库目录权限、系统凭据保存、手动升级与数据保留验证。

首发构建矩阵为 Windows x64、macOS Apple Silicon 和 macOS Intel；Windows ARM64 与 Linux 延后。

交付分两阶段进行：第一阶段完成在线 iframe、首发版 IndexedDB/OPFS 数据模型和共享运行时适配器；第二阶段在这些契约稳定后增加 Tauri 宿主与桌面安装包。AWAI 首次公开上线使用全新浏览器存储命名空间，不读取、迁移或清理旧应用数据。Web 版不提供 PWA 安装入口，避免与具备真实素材库目录的桌面版混淆。

在线版在生成前使用浏览器存储估算值检查空间，剩余空间低于 100 MB 时警告但不阻止生成。若图片生成成功但 OPFS 写入失败，任务标记为“已生成、未保存”，结果暂留当前页面内存并提供立即下载；已开启云端临时保存时仍可尝试上传。应用不得把未完成本地写入的结果显示为已保存。

在线版移除 GitHub Release 更新检查，改为读取 AWAI 同源的 `version.json`。页面重新获得焦点时检查版本；发现新版本且没有运行任务时提示刷新，存在运行任务时延后到任务结束后提示。
