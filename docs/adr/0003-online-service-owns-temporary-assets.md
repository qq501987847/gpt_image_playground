# ADR-0003：AWAI 在线服务独立管理临时素材

## 状态

已接受

## 背景

在线嵌入版需要可选的 24 小时云端临时副本、准确到期时间和服务端补偿清理。现有应用是静态 Vite 前端，Sub2API 则负责身份、API Key、模型中继和计费；把 AWAI 素材生命周期写入 Sub2API 会扩大其业务边界。

## 决策

在 AWAI 仓库中新增独立 Node 服务。PostgreSQL 保存在线任务、对象路径和 `expires_at`，S3 兼容对象存储保存生成结果原图与缩略图。对象存储生命周期负责主删除，Node 后台任务负责补偿清理数据库记录和残留对象。

Sub2API 继续负责用户身份、用户 API Key、模型中继和计费。Sub2API 部署把 AWAI 的精确 HTTPS origin 加入 `cors.allowed_origins`，不使用 `*`。

iframe 从菜单 URL 取得 JWT 后把它放入 `sessionStorage`，并立即从地址栏移除 token。浏览器携带 JWT 直接调用对应 Sub2API 的 `/api/v1/user/profile` 和 `/api/v1/keys`，由用户为各 API 配置选择 Key。完整 Key 只保留在页面内存中，持久化层只保存配置与 Key ID 的绑定；刷新后使用 JWT 重新读取 Key。浏览器携带对应配置绑定的 Key 直接调用 Sub2API 图像或 Gemini 原生中继，AWAI 在线服务不代理模型请求。

在线版默认把生成结果上传至 AWAI 在线服务；用户关闭云端临时保存后，浏览器停止后续上传，但不自动删除尚未到期的已有副本。用户可对已有副本执行立即删除。在线服务携带本次请求的菜单 JWT 调用官方允许列表中的 Sub2API `/api/v1/user/profile` 回验身份，不建立 AWAI 凭据会话表，也不接收用户 API Key。云端上传失败不改变本地生成任务的成功状态。

云端临时副本的生成结果原图单文件上限为 30 MB。浏览器可在上传前提示超限，服务端仍必须独立校验实际接收字节数；超限时拒绝该文件，不删除用户其他未到期素材，也不把生成任务标记为失败。

每名用户所有未到期云端临时副本的滚动总量上限为 1 GB。配额按服务端已确认保存的原图和缩略图实际字节数计算；达到上限时拒绝新上传，不提前清理尚未到期的素材。到期清理释放配额后，用户可继续上传。

上传采用浏览器直传对象存储。AWAI 在线服务回验菜单 JWT，并预检查文件声明和用户剩余配额后，在初始化记录中确定 `expires_at`，签发仅允许写入服务端指定对象键、10 分钟有效的一次性上传地址。浏览器上传完成后调用完成确认接口；服务端读取对象元数据，重新校验实际大小、媒体类型、对象键和配额，校验通过后才把记录置为可用。24 小时保留期从服务端初始化上传时开始，不因上传或确认延迟而顺延。未确认、超时或校验失败的对象由后台任务清理，且不计入用户已用配额。

客户端对同一对象的上传或完成确认失败最多自动重试两次，始终复用服务端分配的对象键，不得触发新的模型请求。两次失败后，生成任务仍保持本地成功状态并显示“仅本地保存”，用户可手动重新发起云端上传。

## 后果

在线部署从纯静态站点变为 Web 前端、Node 服务、PostgreSQL 和 S3 兼容对象存储的组合。在线服务需要数据库迁移、对象生命周期配置、清理任务、监控和备份策略；桌面版不依赖这些云端组件。
