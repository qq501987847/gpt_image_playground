# 005 桌面安装与更新手工检查

Windows 10/11 x64：使用 NSIS 安装包完成首次安装。首发未配置 Authenticode，Windows 可能显示未知发布者警告；用户在系统提示中选择“仍要运行”后继续。确认启动后选择素材库、保存系统凭据、生成一张图片、重启恢复历史；使用签名正确和错误的稳定更新清单分别验证安装与拒绝，错误签名后当前版本仍可启动。

macOS Apple Silicon 与 Intel：分别使用对应架构的 DMG 安装包。首发未使用 Apple Developer ID 或 notarization，Gatekeeper 可能阻止首次打开；用户在“系统设置 > 隐私与安全性”确认“仍要打开”后继续。确认素材库权限、钥匙串提示、生成和重启恢复；分别验证稳定更新的立即更新、稍后提醒、跳过此版本以及验签失败。

本机 Linux 不生成安装包，也不代替上述系统级验证。Windows/macOS 完整安装、升级和回归矩阵由 issue 006 执行。
