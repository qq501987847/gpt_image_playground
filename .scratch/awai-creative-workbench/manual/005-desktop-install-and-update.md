# 005 桌面安装与更新手工检查

Windows 10/11 x64：使用 NSIS 安装包完成首次安装。项目不配置 Authenticode，Windows 可能显示未知发布者警告；用户在系统提示中选择“仍要运行”后继续。确认启动后选择素材库、保存系统凭据、生成一张图片并重启恢复历史。升级时手动运行新版 NSIS，确认素材库、历史和凭据绑定仍可用；取消或安装失败时原有数据不得改变。

macOS Apple Silicon 与 Intel：分别使用对应架构的 DMG 安装包。项目不使用 Apple Developer ID 或 notarization，Gatekeeper 可能阻止首次打开；用户在“系统设置 > 隐私与安全性”确认“仍要打开”后继续。确认素材库权限、钥匙串提示、生成和重启恢复。升级时手动安装对应架构的新版 DMG，确认素材库、历史和钥匙串绑定仍可用。

本项目现在及未来均不配置平台签名或 Tauri updater，不提供应用内自动更新。本机 Linux 不生成安装包，也不代替上述系统级验证。Windows/macOS 完整安装、手动升级和回归矩阵由 issue 006 执行。
